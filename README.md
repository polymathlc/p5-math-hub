# P5 Math Hub 🔢

Interactive mathematics practice for Primary 5 students in Singapore. Features proper fraction rendering using KaTeX.

## Features

- **Learn Mode**: Step-by-step explanations with examples
- **Practice Mode**: Filter by topic and difficulty
- **Quiz Mode**: Timed assessments with score tracking
- **Proper Math Rendering**: Beautiful fractions using KaTeX

## Topics Covered

### Fractions (Current)
- Adding unlike fractions
- Subtracting unlike fractions
- Multiplying fractions
- Dividing fractions (Keep-Change-Flip)
- Fraction of a quantity
- Mixed numbers & improper fractions
- Comparing fractions
- Word problems (Top school level)

### Coming Soon
- Decimals
- Percentage
- Ratio

## Question Sources

Questions are aligned with Singapore P5 Mathematics curriculum and modeled after top school exam papers (Nanyang, Raffles Girls, Rosyth, Catholic High, etc.)

## Running Locally

Simply open `index.html` in a browser. No server required.

## Tech Stack

- Vanilla JavaScript
- KaTeX for math rendering
- CSS Grid & Flexbox for layout
